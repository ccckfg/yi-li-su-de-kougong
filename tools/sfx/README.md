# 《一粒粟的口供》音效合成

纯代码合成（numpy / scipy），不使用任何外部音频素材。

```
python tools/sfx/synth_sfx.py                 # 生成全部 34 个 WAV + sfx_manifest.json
python tools/sfx/synth_sfx.py --only bronze_bell knock_wood   # 只重新生成指定文件
```

输出目录：`film/public/audio/sfx/`，48 kHz / 16-bit，除注明外为单声道。
每个声音用 `crc32(文件名)` + 固定种子派生独立随机数，重复运行结果逐字节一致。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `synth_sfx.py` | 入口：逐个渲染、母带处理、质检、写出 |
| `sfx_config.py` | 采样率、种子、路径、电平、淡入淡出、质检阈值 |
| `sfx_types.py` | `Sound` 规格数据类 |
| `dsp_basic.py` | FFT 噪声整形、滤波、包络、定位叠加 |
| `dsp_synth.py` | 模态合成、噪声脉冲、啁啾、嗡声、时变带通、短混响 |
| `dsp_grain.py` | 颗粒库、泊松时刻、颗粒散布、笔触颗粒云 |
| `master.py` | 去直流、20 Hz 高通、5 ms 淡入、20–80 ms 淡出、峰值归一、量化 |
| `qa.py` | 时长 / 峰值 / RMS / 频谱质心 / 直流 / 削波 / 截断 / 循环接缝检查 |
| `export.py`, `registry.py` | 写 WAV 与 manifest；汇总 34 个声音 |
| `sounds_*.py` | 各声音的合成函数与规格（按主题分组） |

## 母带与质检

- 一次性音效峰值归一到 -3 dBFS，环境声（风、窗外雪、微风、房间声、审讯床、放映机、化验音、火堆）到 -6 dBFS。
- 循环素材（`wind_winter`、`interrogation_bed`、`projector`、`room_tone_seedroom`）全程用首尾相接的方式构造：FFT 整形噪声、整数周期的正弦与调制、回绕叠加、循环高通。淡出取下限 20 ms。
- 每次运行打印：时长、峰值、RMS、频谱质心、有声时长、末尾残余电平、循环接缝指标，并标记静音、削波、直流、末尾截断、有声占比过低、质心越界、接缝跳变。

## 各声音的合成方法

### 天气与环境（`sounds_weather.py`）
- `wind_winter`：100–500 Hz 与 450–1200 Hz 两段整形噪声，由左右声道部分共享的对数正态阵风包络调制（高段更依赖阵风）；叠加 3 次窄带 SVF 哨音（1.7–2.9 kHz，频率缓慢游移，随机声像，回绕放置）。左右声道噪声独立。
- `snow_steps`：4 步，每步 60–120 ms，用 80–140 个 0.8–2.6 ms 噪声颗粒（早密晚疏）加稠密噪声体，经 2–6 kHz 带通得到“咯吱”；再叠一个很轻的 60–260 Hz 落脚闷响。步间隔约 0.55 s，带随机偏差与音量差。
- `snow_window`：60–450 Hz 倾斜噪声加 190–330 Hz 窗腔共振和极轻的空气声，缓慢阵风；两下窗框衰减正弦“嗒”，一声 SVF 扫频“吱”，偏向一侧声像。
- `spring_breeze`：150–2500 Hz 倾斜噪声加 2.2–6 kHz 叶沫沙沙（随阵风与快速颤动调制）；两组鸟鸣为指数上扬正弦啁啾加二次谐波，低通后加一个更暗更轻的延迟反射表示距离。
- `room_tone_seedroom`：60–4500 Hz 倾斜底噪、25–110 Hz 低频嗡鸣、120–900 Hz 缓慢起伏的“远处的风”，全部循环构造。

### 机械与电子（`sounds_machine.py`）
- `lamp_click`：金属模态（2–7 kHz）、塑料壳体（0.8–1.6 kHz）、1 ms 噪声瞬态、11 ms 后的小回弹；随后 50 Hz 基频及 2、3、4、6 次谐波的嗡声，包络先起后压低。
- `lamp_flicker`：50 Hz 基频及 2、3、4、6、8 次谐波的嗡声，被一串 12–60 ms 随机通断（低通软化切换，避免爆音）的门控断续；加电弧噪声，以及在通断边缘和随机时刻出现的 0.6–3 ms 小火花噪声颗粒。
- `interrogation_bed`：38–55 Hz 四个正弦（频率与调制周期数均为整数，保证 60 s 循环），带慢速相位游移与幅度起伏，加低频噪声与轻房间底噪；每秒一下钟表滴答，“滴”（2.35 kHz 起的模态）与“答”（1.48 kHz 起）交替，各带擒纵噪声瞬态和机壳共振。
- `projector`：48 Hz 起的马达谐波（整数周期）加噪声，144 次片门咔哒（每秒 24 下，带微抖动与幅度起伏），7 kHz 以下被 24 Hz 调制的走带沙沙。
- `lab_tone`：四组高频正弦（每组两个略失谐，右声道再失谐），各自缓慢幅度起伏；少量带 3 ms 起音的正弦“滴”，成簇出现，另一声道有一次较轻的回声。
- `scan_sweep`：TPT 状态变量滤波器做 300 Hz→6 kHz 的指数扫频带通噪声，加跟随的正弦（频率为扫频的一半）及二次谐波，38 Hz 轻微颤动，汉宁收尾。

### 室内拟音（`sounds_room.py`）
- `knock_wood`：128–391 Hz 五个衰减模态、78 Hz 门板闷响、指节噪声瞬态；第二下较轻、频率略不同；短混响。
- `bowl_lift`：500–3200 Hz 带随机颤动的摩擦噪声，随后 640–2330 Hz 陶瓷模态“嗒”、陶坛口 220 Hz 空腔共鸣，再有一下更轻的落座声。
- `glass_slide`：70–900 Hz 速度调制的木面摩擦（粘滑颤动）加极轻高频光泽，停住时一下杯底磕声；6 次水晃荡为 150–400 Hz 轻微上扬的衰减啁啾加低通水声。
- `folder_close`：下落时的空气声，纸板拍合噪声瞬态，140–480 Hz 模态闷响，40–250 Hz 低频冲击，后盖落下的小声和一点气流。
- `pen_tap`：4 ms 带通噪声瞬态、700–1100 Hz 衰减正弦、纸面 180 Hz 闷响，13 ms 后一个更轻的回弹。
- `ink_drop`：低通噪声“嗒”、420 Hz 湿润衰减正弦、柔和噪声尾，后面三个渐弱的微小气泡上扬啁啾。

### 纸与颗粒（`sounds_paper.py`）
- `paper_flip`：低（90–600 Hz “呼”）、中、高三段噪声各带高斯包络并错开时间，使频谱重心移动；纤维颤动调制，稀疏纸屑颗粒，末尾落页的低频拍声。
- `bag_tip`：两段皱纸（细颗粒加较大颗粒，密度钟形），随后 95–215 Hz 模态与低通噪声构成闷闷的落桌声，带一点纸的拍击。
- `grain_pour_bag`：非齐次泊松过程（速率指数衰减）生成约 2600 个 1–3 ms 高通噪声颗粒，幅度随流量；50–320 Hz 的纸袋鼓动、稀疏纸袋皱响、起始落底声。
- `grains_spill`：开头约 0.6 s 为密集木质衰减正弦颗粒（音高随机）加噪声颗粒；之后每粒按几何衰减的间隔和幅度弹跳（音高固定），部分带一小段低通滚动噪声，密度逐渐减小至停止。
- `charcoal_scratch`：四道笔触，每道的颗粒密度和幅度跟随钟形速度曲线（0.4–1.6 ms 颗粒，1.2–7.5 kHz），叠加 600–3500 Hz 的纸粗糙感。
- `paper_brush`：两道笔触，500–3000 Hz 倾斜噪声乘平滑速度曲线（毛刷摩擦的轻颤），起笔按压声，稀疏的宣纸轻响颗粒。

### 手工与器物（`sounds_craft.py`）
- `clay_rub`：120–1400 Hz 倾斜噪声乘往复速度（每 0.34 s 换向）与挤压颤动，加湿润的上扬气泡啁啾，换向处一下低频黏响。
- `knife_carve`：180/420/960 Hz 木板模态、硬噪声瞬态、2.5 kHz 小高音；刮擦为 0.8–6.5 kHz 颗粒云加 300–1200 Hz 阻力噪声，最后落下几片木屑的小“嗒”。
- `plaster_crumble`：泊松碎屑（噪声颗粒和 1.5–4.5 kHz 小滴答混合，速率衰减，并有 5 次连串掉落），少量柔和落地声，细尘噪声，开头一下起皮的脆响。
- `bamboo_slips`：每次碰撞为自由-自由梁模态（比例 1、2.76、5.40、8.93，高阶衰减更快，基频 850–2200 Hz 随机），钟形密度的泊松时刻，部分带二次碰撞，叠加极轻的皮绳摩擦。
- `bone_crack`：宽带“咔”（900–6000 Hz 噪声瞬态、2–5 kHz 模态、560/880 Hz 闷响），之后速率衰减的泊松小裂纹颗粒，加极轻的烧灼嘶声。
- `bronze_bell`：220 Hz 基频，非谐泛音比 1、2.4、3.9、5.4、6.8、8.3、9.9；每个分音拆为两个相差 0.6–2.2 Hz 的双音产生拍频，高阶衰减更快（T60 4.2 s 到 0.5 s），加低八度嗡鸣、槌击瞬态与 0.9 s 短混响。

### 火、水、土与过渡（`sounds_nature.py`）
- `fire_crackle`：35–380 Hz 缓慢起伏的“呼呼”加 380–2200 Hz 闪烁；泊松爆裂分三类（噪声颗粒、衰减正弦“啪”、带低频的大裂），随机声像，部分带连续余响。
- `whoosh_zoom`：两路 SVF 带通噪声做 200 Hz→4 kHz 指数扫频（一路宽、一路窄），幅度随扫频升高，到顶后 90 ms 汉宁收尾，整体 5.5 kHz 低通。
- `water_pour_soil`：400–6000 Hz 倾斜水流噪声乘随时间的流量曲线，细小水滴颗粒，落土的 90–220 Hz “噗”（泊松，速率随流量），开头铁皮水壶的金属轻响，收尾稀疏水滴。
- `soil_soak`：泊松气泡（速率钟形）：每个为 900–3600 Hz 上扬的短啁啾，半径越小频率越高、衰减越快，加细小爆破声；细微渗水嘶声和几粒土屑。
- `seed_crack`：3 ms 高频细裂瞬态、30 ms 的 1.5–3.5 kHz 小吱声、300 Hz 微弱体鸣，随后一次更轻的二次细裂和一点湿润空气声。
