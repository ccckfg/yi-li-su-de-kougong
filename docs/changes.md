## 二、按事实核查改掉的画面/字幕文字（已执行）

- 档案夹表头：「农作物种质资源**征集**表」（真实表名是「征集表」）。
- S28 叠的手写字段换成真实字段：种质名称 黄毛 / 地点 晋北某村 / 提供人 王桂兰，83岁 / 种质类型 地方品种 / 主要特性 抗旱 耐贫瘠 广适 / 其他特性 熬粥香 / 备注 当地种植四十余年（据提供人口述）。
- 化验段字幕：「谷子由青狗尾草驯化而来。2023年，我国科研团队的谷子泛基因组研究，为『谷子起源于中国』提供了遗传学证据。」（原句「世界各地的谷子都起源于中国」是新闻稿口径，论文没这么说）
- 半坡展签：「六千多年前 · 陕西西安 · 半坡」（原为「约六千年前」，更准确是六千多年前）。
- 谷粒外观：浅黄、半哑光、表面细密乳突、外稃包着内稃有一道接缝（原道具卡写「有光泽」）。
- 显微镜纵切面：稃壳 → 一圈空腔 → 果种皮细线 → 单层糊粉层 → 淀粉胚乳 → 基部一侧的小胚（约占整粒 9%），胚没有画大。
