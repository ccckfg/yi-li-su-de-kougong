# 任务卡：用代码合成短片音效（Python + numpy/scipy，不用任何外部音频素材）

你在给一部 3 分钟的电影感短片《一粒粟的口供》做音效。基调：克制、写实、安静、有质感（参考电影拟音，不要游戏化、不要卡通）。
不要问我问题，按卡执行。

## 环境
- Python 3.14，已装 numpy、scipy、pydub。不要安装别的包，不要联网下载音频。
- 工作目录：`D:\Project N2\AI _Videos\`
- 脚本写到 `D:\Project N2\AI _Videos\tools\sfx\synth_sfx.py`（一个脚本生成全部文件，可重复运行，固定随机种子）。
- 输出到 `D:\Project N2\AI _Videos\film\public\audio\sfx\`，WAV，48000 Hz，16-bit；除注明立体声外都用单声道。
- 再写一份 `D:\Project N2\AI _Videos\film\public\audio\sfx\sfx_manifest.json`：`{文件名: {"dur": 秒, "peak_db": 峰值dBFS, "rms_db": 均方根dBFS, "desc": 中文描述}}`。

## 通用要求
- 每个文件开头 5 ms 淡入、结尾 20–80 ms 淡出，绝不能有爆音/直流偏移（做高通 20 Hz）。
- 峰值归一到 -3 dBFS（环境声类归一到 -6 dBFS）。
- 用物理上说得通的合成方法：滤波噪声、颗粒合成（granular）、模态合成（多个衰减正弦/共振峰）、包络整形、卷积短混响（自己生成指数衰减噪声脉冲响应）。
- 写实优先：真实声音都有随机性，重复的颗粒要随机化音高、音量、间隔。
- 你听不到声音，所以每个文件生成后要做客观检查：时长、峰值、RMS、频谱质心（打印出来），确保没有削波、没有静音文件、没有异常长的尾巴。
